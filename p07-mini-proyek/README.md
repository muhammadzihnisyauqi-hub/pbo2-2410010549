# Katalog Buku Perpustakaan

## Deskripsi Proyek

Katalog Buku Perpustakaan merupakan aplikasi desktop berbasis Java Swing yang digunakan untuk mengelola data buku. Aplikasi ini dibuat sebagai mini proyek Praktikum PBO 2 Pertemuan 7 dengan menerapkan `JTable`, `AbstractTableModel`, menu, pencarian, dan dialog.

- Membantu memahami konsep dan fungsi komponen Java Swing yang digunakan dalam proyek.

Penggunaan AI hanya sebagai alat bantu. Penyesuaian proyek, pemeriksaan hasil, dan pengujian aplikasi dilakukan oleh saya.
